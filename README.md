# Olist Marketplace Analytics: Category, Seller, Delivery & Retention Analysis

End-to-end analytics project on **real data**: the Olist Brazilian E-Commerce Public Dataset (about 100K orders from a
Brazilian online marketplace, 2016-2018). It covers data cleaning, SQL, category and seller analysis, delivery
experience, payment behaviour, customer retention and a short-term forecast, with Tableau-ready outputs.

## Business questions
1. Which categories and sellers drive GMV, and where is the concentration and risk?
2. How does delivery performance affect customer reviews?
3. What do payment instalments and price points say about demand?
4. How well does the marketplace retain customers, and what is the forecast?

## Key findings
See `reports/insights_report.md` for all numbers (generated by code). Highlights:
- Late deliveries (6.8% of delivered orders) average 2.27 stars vs. 4.29 on time.
- The top 10% of sellers generate about two-thirds of GMV; 18 of 74 categories make up 80%.
- Only about 3% of customers buy a second time, so retention is the biggest open opportunity.
- Instalment orders have a much larger AOV (R$172 vs. R$100), which is associated with higher-priced baskets.

## Data
Download the dataset from https://www.kaggle.com/olistbr/brazilian-ecommerce and put the 9 CSV files into `data/raw/`.
The raw data is **not** included here. Check the licence on the Kaggle page before republishing any data.

## How to run
```
pip install -r requirements.txt
python src/01_prepare_data.py     # clean + join -> data/processed/
python src/02_analyze.py          # analysis, charts, Tableau CSVs, report
python src/03_run_sql.py          # the same analyses in SQL (SQLite)
```
or `./run_all.sh`.

## Folder structure

## Limitations (be ready to say these in interviews)
- Olist is a general marketplace, not fashion-specific; fashion and accessories are about 2.5% of GMV and are analysed
  as a separate group. The dataset has no discount, traffic or ad data, so there is no conversion or promotion analysis.
- All results are observational. Associations (late delivery and reviews, instalments and AOV) are not proven causes.
- Only 20 months of usable history, so the forecast uses simple level/trend models and cannot estimate seasonality.
  The Black Friday figure is a scenario based on one observation.
- Amounts are in Brazilian reais; the data covers 2017-2018, so findings may not reflect today's market.
- GMV here means item value of valid orders (freight excluded).

## Skills demonstrated
Python (pandas, NumPy, Matplotlib), SQL (CTEs, window functions), data cleaning and validation, KPI design,
category/ABC and Pareto analysis, seller scorecards, cohort and RFM-style segmentation, forecasting with holdout validation,
data storytelling, Tableau (dashboard guide).
